Networking costs in AWS per GB:
-> In bound traffic is free
-> within the az, communication through Private IP is free
-> communication between AZ in a region using public IP (Elastic) is $0.02
-> communication between AZ using private IP  will be chargeable at $0.01
-> communication between 2 regions will be charged at $0.02 

Use Private IP instead of public IP for good savings and better network performance
Use same AZ for maximum savings (cost of high availability)
